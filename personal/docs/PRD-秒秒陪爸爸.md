# PRD：秒秒陪爸爸（工作陪伴与休息引导）

**文档版本**：v1.0  
**平台**：iPhone（Safari / 可「添加到主屏幕」的 Web 应用形态）  
**形态**：单页 Web（HTML/CSS/JS），不上架 App Store；数据本地存储。

---

## 1. 背景与目标

### 1.1 背景

使用者为算法工程师，工作强度高、加班多、易久坐。希望用**女儿「秒秒」的陪伴形象**与**温和的节奏**，在不影响工作尊严的前提下，提醒休息、降低「一直拼」的无意识状态。

### 1.2 产品目标

| 目标 | 说明 |
|------|------|
| G1 节奏干预 | 以 50 分钟专注 + 3 分钟休息为默认单元，形成可预期的工作节律。 |
| G2 情感连接 | 通过「秒秒」安静陪伴与到点台词，强化家庭情感而非说教。 |
| G3 自我觉察 | 休息后小结 + 当日累计专注时长，提供轻量、无压力的反馈。 |
| G4 低摩擦使用 | 主路径清晰；不依赖外链跳转即可完成核心闭环（放松角为意图引导型）。 |

### 1.3 非目标（本期不做）

- 不上架 Apple App Store；本期不承诺后台/锁屏下的计时精度（以前台使用为主）。
- 不做账号体系、云端同步、社交分享。
- 不做 25 分钟中途久坐提醒。
- 放松角不强制跳转外部 App（可为纯文案 + 可选极少量内嵌图）。

---

## 2. 用户与场景

### 2.1 使用者

主要使用者：丈夫（工程师）。  
内容供给者：妻子（礼物策划与文案）；女儿「秒秒」为形象与台词载体（婴儿期，台词为成人代笔文字）。

### 2.2 核心场景

1. 工位或通勤间隙打开手机，进入页面开始一段专注。  
2. 50 分钟结束后被「秒秒」温和打断，进入 3 分钟休息。  
3. 在放松角选择一项「小事」作为休息意图，休息结束后查看小结。  
4. 主动点击「开始下一段」后，才进入下一轮 50 分钟（防止无意识连轴转）。

---

## 3. 信息架构

```
秒秒陪爸爸（单页，分区滚动或 Tab）
├── ① 陪伴工作台（默认首屏）
│   ├── 秒秒形象区（安静等待 / 到点跳出）
│   ├── 给爸爸加油文案区
│   ├── 专注倒计时（50:00）
│   └── 主操作：开始这一段工作 / 暂停（可选）/ 提前结束并休息（可选）
├── ② 放松角（列表 + 选中态）
│   └── 六项：看秒秒照片 / 陪秒秒玩 / 泡茶 / 听音乐 / 跑步 / 打盹儿
└── ③ 今日小结（可与休息结束弹层合并）
    └── 今日累计专注时长、完成段数
```

---

## 4. 状态机与关键规则

### 4.1 状态定义

| 状态 ID | 名称 | 说明 |
|---------|------|------|
| S0 | 待机 | 未在专注；秒秒安静；展示「给爸爸加油」类文案轮换。 |
| S1 | 专注中 | 50 分钟倒计时运行中；秒秒仍为「安静等待」姿态。 |
| S2 | 休息中 | 3 分钟倒计时；可并行展示放松角选中项提示。 |
| S3 | 休息结束待确认 | 展示小结（本段结束、今日累计、完成段数）；**不自动进入下一轮专注**。 |

### 4.2 关键规则（必须满足）

1. **专注时长**：默认 50:00，到 S2；中途无 25 分钟提醒。  
2. **休息时长**：固定 3:00。  
3. **下一轮专注门槛**：仅在用户点击「开始下一段」后，从 S0/S3 进入 S1；禁止休息结束自动开始 50 分钟。  
4. **统计口径**：「今日工作时长」= 当日**已完成**的专注段时长之和（每完成一段 +50 分钟，或按实际完成比例若未来支持提前结束规则——**本期建议**：仅「正常跑满 50 分钟并进入休息」计为完成一段 +50 分钟；若「提前结束并休息」是否计入，需在实现时二选一并在本文档「待定」中锁定——**推荐**：提前结束不计入完成段，避免刷数据）。  
5. **跨天**：以设备本地自然日 0:00 重置「今日」统计（或首次打开页面的日期切换时重置，二选一，实现简单即可）。

### 4.3 待定（实现前锁定其一）

- **提前结束专注**：是否允许、是否计入今日时长与段数。  
- **暂停**：是否提供；暂停是否冻结倒计时（推荐冻结）。

## 5. 功能需求

### 5.1 陪伴工作台

| ID | 需求 | 优先级 |
|----|------|--------|
| F1 | 展示秒秒形象：至少两种视觉状态（安静等待 / 到点跳出提示）。 | P0 |
| F2 | 展示轮换加油短句（2～5 条），避免单句疲劳。 | P1 |
| F3 | 开始专注：进入 50 分钟倒计时。 | P0 |
| F4 | 50:00 到点：全屏或强视觉层展示女儿台词，例如「爸爸休息一下吧～」+ 一句具体动作建议（站起、喝水等）。 | P0 |
| F5 | 用户确认后进入 3 分钟休息倒计时。 | P0 |
| F6 | （可选）暂停 / 提前结束并休息。 | P2 |

### 5.2 放松角

| ID | 需求 | 优先级 |
|----|------|--------|
| R1 | 展示六项卡片或列表，单选；每项含主标题 + 可选一句副文案（如跑步「两三分钟也算数」、打盹儿「闭眼歇一会儿」）。 | P0 |
| R2 | 不使用 emoji 作为图标；使用线性图标或纯文字排版区分。 | P0 |
| R3 | 选择结果可在休息 3 分钟内弱展示（意图标签即可）。 | P1 |

**固定文案项（主标题）**

1. 看看秒秒照片  
2. 陪秒秒玩一下  
3. 给自己泡一杯茶  
4. 听一首音乐  
5. 跑个步  
6. 打个盹儿  

### 5.3 小结与统计

| ID | 需求 | 优先级 |
|----|------|--------|
| M1 | 每次 3 分钟休息结束后展示小结：本段已结束、今日累计专注时长、今日完成段数。 | P0 |
| M2 | 数据持久化：使用 `localStorage`（或等价）按日存储；清缓存或换机则丢失——可接受。 | P0 |
| M3 | 小结后仅「开始下一段」进入下一轮 50 分钟。 | P0 |

---

## 6. 内容与资产

- **秒秒形象**：静态图或轻量帧动画（GIF/Lottie 二选一）；资源体积控制以利手机加载。  
- **文案**：语气自然、短句、不内疚感（避免「你又久坐了」类指责）。  
- **图标**：系统感线性图标或小型 SVG，禁止用 emoji 充当图标。

---

## 7. 技术约束（摘要）

- 单页 Web；iPhone Safari 兼容；建议支持「添加到主屏幕」。  
- 锁屏/后台长时间切换时计时可能漂移——产品层接受，可在首次使用简短说明。  
- 无障碍：按钮可点击区域 ≥ 44×44pt（见设计规范）。

---

## 8. 验收标准（MVP）

1. 完成 S0→S1→S2→S3 闭环，且 S3 后**必须**点「开始下一段」才回到 S1。  
2. 无 25 分钟中途提醒；休息固定 3 分钟。  
3. 放松角六项可展示并可单选（选中态可见）。  
4. 今日累计时长与段数在休息结束后正确更新（与 PRD 口径一致）。  
5. 视觉符合《设计规范》文档：无渐变、无 emoji 图标、非通篇居中布局。
