# 界面设计规范：秒秒陪爸爸

**文档版本**：v1.0  
**参考气质**：极简卡片、柔和阴影、安静背景、左对齐叙事感（对标「Reflections」类治愈工具的视觉节奏，**禁止**紫色渐变与渐变底色）。  
**设备**：iPhone（Safari / Web），安全区与触控以 iOS HIG 为底线。

---

## ① Style 整体风格

| 项 | 规范 |
|----|------|
| 关键词 | **极简**、留白、少装饰、信息层级靠字号与字重而非描边堆砌。 |
| 图形语言 | 扁平色块 + 细线图标；无渐变（含背景、按钮、文字渐变）。 |
| 布局哲学 | **避免「通篇居中」**：主标题与正文以**左对齐**为主；数字倒计时等强锚点可局部居中或偏一侧，与左文形成张力。 |
| 质感 | 大面积单色底 + 浮起卡片；不用玻璃拟态强反光。 |

---

## ② Mood 情绪氛围

| 项 | 规范 |
|----|------|
| 关键词 | **温暖、治愈、安静、被接纳**。 |
| 语气 | 短句、平视、不指责；到点提醒是「邀请休息」而非「纠错」。 |
| 视觉温度 | 背景偏暖中性白/米白；强调色偏陶土/苔绿等**有体温**的纯色（见③）。 |

---

## ③ Color 色彩（扁平 + 1～2 个强调色）

**禁止使用**：任何线性/径向渐变；霓虹高饱和大面积铺色。

### 语义色板（可在实现时微调 hex，保持角色不变）

| Token | 用途 | 建议值 |
|-------|------|--------|
| `--bg-page` | 页面安静底 | `#F7F4EF` 暖米白 |
| `--bg-elevated` | 卡片表面 | `#FFFFFF` |
| `--text-primary` | 主文案 | `#1A1715` 暖黑 |
| `--text-secondary` | 次级说明 | `#5C5855` |
| `--text-tertiary` | 辅助、禁用态 | `#9C9894` |
| `--border-subtle` | 分割线、描边 | `#E8E4DE` |
| `--accent-primary` | 主按钮、选中态、关键数字强调 | `#B85C4A` 陶土红（纯色） |
| `--accent-secondary` | 标签、弱强调、图标描边hover | `#6B7D6A` 苔绿（纯色） |

### 使用规则

- **强调色 1（陶土）**：每屏最多 1 个主 CTA（如「开始这一段工作」「开始下一段」）。  
- **强调色 2（苔绿）**：放松角选中 chip、次要按钮、图标焦点。  
- **错误/警示**：尽量不用刺眼红；可用深陶土 + 文案，避免破坏治愈感。

## ④ Typography 字体

**平台说明**：iPhone 上优先使用系统 **PingFang SC**（Web：`font-family: -apple-system, BlinkMacSystemFont, "PingFang SC", "Helvetica Neue", sans-serif`）。

| 层级 | 字重 | 字号 | 行高 |
|------|------|------|------|
| **大标题**（屏级锚点，如「秒秒在等你」） | PingFang **Semibold** | **28 px** | 1.35 |
| **标题**（区块标题，如「放松角」） | PingFang **Semibold** | **22 px** | 1.4 |
| **小标题** / 卡片标题 | PingFang **Semibold** | **17 px** | 1.45 |
| **正文** | PingFang **Regular** | **16 px** | **1.5**（正文区间 **1.4～1.6** 内取 1.5） |
| **辅助说明** / 标签 | PingFang **Regular** | **13 px** | 1.45 |
| **倒计时数字**（视觉锚点） | 可选用 **Semibold** 或等宽数字字体 | **40～48 px**（单屏一个主数字） | 1.1 |

### 规则

- **大小对比**：每屏至少 1 处「28 px 级」或「40 px+ 数字」作为视觉锚点，其余降级到 16～17 px。  
- **数字**：倒计时建议 `font-variant-numeric: tabular-nums` 减少跳动。  
- **不要用渐变字**。

## ⑤ Layout 布局

| 项 | 规范 |
|----|------|
| **容器最大宽度** | **420 px**（手机 Web 主内容区）；在更宽视口（如 iPad）上内容仍限制在 420 px 内**左对齐或略偏左**，两侧留白，**避免整栏居中「海报块」**。若需与 PRD 中「1200px」桌面共存：桌面外框 max-width **1200px**，内部手机预览列仍 **420px** 左对齐。 |
| **边距** | 水平 **20 px**（含安全区 inset）；垂直区块间距 **24～32 px**。 |
| **栅格** | 非严格 12 栅格；以「左对齐主列 + 卡片内边距 16～20 px」为主。 |
| **首屏结构建议** | 上：左对齐大标题 + 一句副文；中：秒秒形象（可略偏左，占宽 55%～70%）；下：左对齐主按钮 + 次级文字链。 |
| **放松角** | 单列列表卡片；左对齐标题 + 右侧小圆点/细线图标，**非居中九宫格**。 |

## ⑥ Components 组件风格

### Button（主按钮）

- **圆角**：**999 px**（全圆角胶囊）或 **14 px** 统一圆角（二选一全站一致；推荐 **14 px** 更克制）。  
- **填充**：**实色** `--accent-primary`，文字 `#FFFFFF`。  
- **高度**：最小 **48 px**（触控友好）。  
- **次按钮**：描边 `1px solid --border-subtle` + 背景 `--bg-elevated`，文字 `--text-primary`。

### Card

- **背景**：`--bg-elevated`。  
- **圆角**：**16 px**。  
- **阴影**（柔和层次）：`0 8px 24px rgba(26, 23, 21, 0.06)`，hover/press 时微抬升见⑦。  
- **内边距**：**16～20 px**。

### Input / 选择（放松角单选）

- **形态**：**填充式**列表行——选中时背景为极浅强调：`rgba(184, 92, 74, 0.08)` + 左侧 **3 px** 实色条（`--accent-primary`）。  
- **无 emoji**；左侧可用 **24 px** 线性图标或留白 + 字重对比。

### 底部安全区

- 固定底栏需预留 `padding-bottom: env(safe-area-inset-bottom)`。

## ⑦ Animation 动效

| 类型 | 规范 |
|------|------|
| **入场** | **fade**：`opacity 0→1`，时长 **220～320 ms**。 |
| **缓动** | `cubic-bezier(0.25, 0.1, 0.25, 1)`（接近 ease，略干净）；到点弹层可用 `cubic-bezier(0.34, 1.2, 0.64, 1)` 轻微弹性（**禁止**夸张弹跳）。 |
| **微交互** | 卡片 **hover/active 抬升**：阴影加深为 `0 12px 32px rgba(26, 23, 21, 0.09)`，translateY **-2 px**，时长 **180 ms**。（触摸设备以 `:active` 为主。） |
| **秒秒到点** | 「跳出」：**scale 0.96→1 + fade**，总时长 **300～400 ms**；避免闪烁高频循环。 |

## ⑧ Iconography 图标与插图

| 项 | 规范 |
|----|------|
| **禁止** | 使用 **emoji** 作为 UI 图标或列表前缀。 |
| **推荐** | **1.5 px～1.75 px** 线宽的 SVG 线性图标（如播放、茶叶、跑鞋、月亮、相册框），描色 `--text-secondary`，选中 `--accent-secondary`。 |
| **秒秒形象** | 独立插图位，不与图标体系混用；保持柔和边缘与低对比阴影或无阴影扁平插画均可。 |

## 参考图对齐与差异（摘要）

| 参考图（Reflections）气质 | 本产品采纳 | 本产品拒绝 |
|----------------------------|------------|------------|
| 大衬线标题 + 安静留白 | 大标题锚点 + 左对齐叙事 | 紫色系与渐变背景 |
